# Expected user time

Normal case: roughly 20-30 minutes of active user time.

- VM/account creation and verification: 8-15 min
- Bitvavo API key + exact IP whitelist + permission check: 3-5 min
- GitHub fine-grained token scoped to one repo: 2-4 min
- paste three secrets into the prepared environment file and run the prepared install/start commands: 3-5 min
- final explicit dry-run/small live test approvals: 2-3 min

Provider verification or free-tier capacity issues can extend elapsed time without increasing configuration work materially.
