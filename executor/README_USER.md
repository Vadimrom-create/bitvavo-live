# What the user will eventually do

Nothing in this folder requires the user to edit Python, upload files manually or type order parameters.

The user's only setup actions are account/security actions that cannot be delegated:

- create the fixed-IP VM;
- create the restricted Bitvavo API key;
- create the restricted GitHub fine-grained token;
- paste those secrets once into the VM environment file.

Everything else is handled by the prepared installer, service and ChatGPT/GitHub workflow.
